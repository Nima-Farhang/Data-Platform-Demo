# Architecture Decision Records

This folder stores Architecture Decision Records (ADRs) for important platform-level choices.

Capture decisions here when we need a durable record of why a shared infrastructure pattern, security control, naming rule, or deployment approach was chosen.

Keep ADRs focused on reusable platform concerns. Product-specific decisions belong in the relevant data product repository.
